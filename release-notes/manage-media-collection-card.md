# Manage media Collection-style card

- Replaces the narrow Movie, Series, Music, and Book management slide-over with
  a centered artwork-backed card based on the refreshed Report an Issue layout.
- Presents each available management section as a darker inset subcard while
  preserving requests, downloads, issues, server links, availability actions,
  watch data, and destructive confirmations.
- Uses visible page spacing, the shared card shadow and border, and a standard
  red Cancel action so management dialogs follow the same visual language as
  Collection Details.
